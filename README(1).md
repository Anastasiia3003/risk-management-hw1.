# risk-management-hw1

Практичне завдання з аналізу ринкового ризику в R. Розрахунок Value at Risk (VaR) та Expected Shortfall (ES) для акцій Apple (`AAPL`) і фондового індексу S&P 500 (`^GSPC`).

Скрипт розміщено в `scripts/main_analysis.R`. Він завантажує щоденні дані з Yahoo Finance за останні три роки, обчислює логарифмічні дохідності, оцінює ризик історичним і параметричним (нормальним) методами та будує гістограми з лініями історичного VaR.

## Як запустити

1. Відкрий папку проєкту в RStudio.
2. Відкрий `scripts/main_analysis.R`.
3. Запусти весь скрипт кнопкою **Source**. Потрібне підключення до інтернету для завантаження котирувань і пакетів R.
4. Після успішного запуску результати збережуться в папці `data/`, а таблиця та посилання на графіки в цьому README оновляться автоматично.
