# Risk Management — Homework 1

## Мета роботи

Оцінити щоденний ринковий ризик двох активів за допомогою Value at Risk (VaR) та Expected Shortfall (ES), використовуючи історичний і параметричний (нормальний) методи.

## Активи та джерело даних

- Apple Inc. (`AAPL`) — скориговані ціни закриття (Adjusted Close).
- Індекс S&P 500 (`^GSPC`) — скориговані ціни закриття (Adjusted Close).
- Джерело: Yahoo Finance, завантаження через пакет `quantmod`.
- Період: останні три роки від дати запуску скрипту.

## Як запустити аналіз

1. Встановити R та RStudio.
2. Відкрити клонований проєкт у RStudio.
3. Відкрити `scripts/main_analysis.R` та натиснути **Source**.
4. Під час першого запуску скрипт за потреби встановить пакети `quantmod`, `PerformanceAnalytics` і `ggplot2`. Для завантаження котирувань потрібен доступ до інтернету.
5. Після завершення перевірити результати в консолі та файлі `data/risk_metrics_summary.csv`. Скрипт автоматично оновить таблицю нижче у `README.md`.

## Основні методи

| Показник | Метод |
|---|---|
| Historical VaR | Історичний квантиль дохідностей для рівня довіри 95% та 99% |
| Parametric VaR | Нормальний (Gaussian) метод для рівня довіри 95% та 99% |
| Historical ES / CVaR | Середній збиток у хвості розподілу для рівня довіри 95% |

## Обмеження

VaR та ES оцінено за історичними щоденними дохідностями. Параметричний VaR припускає нормальний розподіл дохідностей, що може не повністю відображати екстремальні ринкові рухи. Результати залежать від вибраного періоду та доступності даних на Yahoo Finance.
